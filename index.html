🚀 Guía Definitiva de Instalación: AttackBox en Windows

Bienvenido a la Matrix. Aquí tienes todas las instrucciones y el listado absoluto de comandos para controlar tu entorno de hacking.

🔗 Repositorio Oficial de GitHub

👉 github.com/JafetBrito/tryhackme-attackbox 👈

🛠️ Paso 1: Instalar Docker Desktop

Docker es el motor que ejecutará nuestro Kali Linux virtualizado sin afectar a tu Windows.

1. Descarga Docker Desktop para Windows.

2. Al instalar, asegúrate de marcar la casilla para usar WSL 2 (Windows Subsystem for Linux).

3. Abre el programa y espera a que el icono se ponga verde indicando que el motor está corriendo.

📦 Paso 2: Clonar el Código

Abre tu terminal de PowerShell y descarga los archivos del canal:

git clone https://github.com/JafetBrito/tryhackme-attackbox.git
cd tryhackme-attackbox

⚠️ Importante: Mueve tu archivo .ovpn descargado de TryHackMe adentro de la carpeta "workspace" antes de continuar.

🏗️ Paso 3: Construir el Entorno (Primera Vez)

La primera vez que levantes la máquina tomará unos minutos mientras descarga todo. Ejecuta:

docker compose up -d --build

💻 Paso 4: Entrar a la AttackBox (Interfaz Gráfica)

Abre tu navegador (Chrome o Edge) e ingresa a:

http://localhost:8080/vnc.html

Haz clic en el botón Connect y usa la contraseña: kali

🛡️ Paso 5: Enlazar la VPN

Dentro de la terminal gráfica de tu AttackBox, ejecuta:

openvpn --config /workspace/tu_archivo.ovpn &

El ampersand (&) al final es para que corra en segundo plano. Verifica con ip a que exista la tarjeta tun0.

🧰 LA CAJA DE HERRAMIENTAS: Todos los comandos de Docker

Aquí tienes la lista completa de comandos que necesitarás para operar el entorno en el día a día. Todos se ejecutan desde tu PowerShell de Windows, dentro de la carpeta del proyecto.

🟢 Encender la máquina (Día a día)

Cuando ya la construiste la primera vez y solo quieres prenderla para jugar:

docker compose up -d

Enciende el contenedor en segundo plano en cuestión de segundos.

🔴 Apagar la máquina

Para cerrar la AttackBox y liberar tu memoria RAM:

docker compose down

🔄 Reconstruir la máquina (Aplicar cambios)

Si modificaste el Dockerfile (por ejemplo, para agregar una nueva herramienta), debes forzar a que se reconstruya:

docker compose up -d --build

⌨️ Entrar a la terminal directa (Sin entorno gráfico)

Si no quieres usar el navegador y solo quieres una terminal rápida desde tu PowerShell:

docker exec -it kali_thm bash

💥 Destrucción Total (Limpieza Profunda)

Si algo se rompió, quieres borrar absolutamente todo rastro de la AttackBox y liberar espacio en el disco duro:

docker compose down -v --rmi all

⚠️ Advertencia: Esto borrará la imagen descargada de Kali. Tendrás que volver a descargar los 2GB la próxima vez que uses --build.

📋 Ver los registros (Logs)

Si el contenedor no enciende o la página web no carga, esto te mostrará los errores de fondo:

docker compose logs -f

Usa Ctrl + C para salir de esta vista.

⬇️ Actualizar el código desde GitHub

Si Jafet Brito sube una nueva versión de la AttackBox al repositorio, puedes actualizar tus archivos locales con:

git pull origin main
